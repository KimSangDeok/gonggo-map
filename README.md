# prefs 가지

공고 지도(https://kimsangdeok.github.io/gonggo-map/) 페이지의 **기기 동기화** 설정 파일과 **기기 오류·동작 기록**만 두는 가지입니다.

- `prefs.json`: 지도 범례 체크(단지 종류·최소 평형·복층·준공·건물 종류·접수 끝난 곳 빼기)와 공고 확인 표시. 개인정보 없음.
- `log/<기기 id>.json`(2026-11-19~): 기기별 오류·동작 기록 — 스크립트 오류, 그림·자료를 못 불러온 것, 지도·동기화·알림 실패, 느린 요청, 페이지가 갑자기 다시 열린 것과 그 직전 동작, 기기 종류(UA·화면). 새 기록이 생기면 같은 토큰으로 올림(3분 간격, 최근 150건). 기술 정보만 — 금액·7~8자리 숫자·토큰·바깥 사이트 주소의 경로는 지우고, '내 조건'·'보증금·대출'·동기화 창 안에서 누른 글자는 안 적음. Claude 가 gh-pages 가지의 `tools/read_logs.py` 로 읽음.
- 페이지가 기기마다 GitHub API로 읽고 씀(이 저장소 Contents 읽기·쓰기만 되는 토큰을 기기 브라우저에 저장).
- gh-pages(사이트)와 따로라 바꿔도 사이트가 다시 빌드되지 않음.
